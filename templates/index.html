API Usage
Available Endpoints:
Get All Data GET /api/data

Returns all financial data collected from the last scraping.

Try it
Get Data by ID GET /api/data/{id}

Returns a specific financial data item by its ID.

Get Data by Name/Symbol GET /api/getDataByName/{name}

Returns a specific financial data item by its name or symbol (case insensitive).

Get Multiple Stocks by Names/Symbols GET /api/getBulkDataByNames?names=symbol1,symbol2,symbol3

Returns multiple financial data items by comma-separated names/symbols.

Force Data Update POST /api/force-update

Triggers an immediate data update from the source website.

Get System Status GET /api/status

Returns information about the system status and last update time.
